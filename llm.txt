# Global News Scraper PHP

> PHP client for scraping full-text news articles from 300+ sources worldwide via Apify: switch on any sources, get one merged Laravel collection of typed articles.

Key facts:
- Package: `bitesizedinsights/global-news-scraper`
- Install: `composer require bitesizedinsights/global-news-scraper`
- PHP: ^8.3, Guzzle ^7, illuminate/collections
- Namespace: `GlobalNewsScraper`
- Entry class: `GlobalNewsScraper\Client`
- Auth: Apify API token, set via `Client::setApifyKey()`, falls back to env `APIFY_API_TOKEN` or `APIFY_TOKEN`

## Docs
- [README](https://github.com/bitesizedinsights/global-news-scraper-php/blob/master/README.md): usage
- [Actors](https://apify.com/bite-sized-insights): the underlying Apify collector Actors

## API
- `Client::__construct(?Config $config = null, ?GuzzleHttp\ClientInterface $http = null, ?Closure $sleeper = null)` - `$sleeper` waits between retries (tests)
- `Client::setApifyKey(string $apiKey): static` - sets the Apify API key; without it `APIFY_API_TOKEN` or `APIFY_TOKEN` is read from the environment, and `MissingApiKeyException` is thrown on the first API call if neither is set
- `Client::scrape(array|Collection|Source|SourceGroup|Collector $sources, ?string $searchQuery = null, DateTimeInterface|string|null $startDate = null, DateTimeInterface|string|null $endDate = null, ?int $limit = null, bool $withSentiment = false, bool $withTags = false, bool $withSummary = false, bool $with5w1h = false, bool $withLanguageDetection = false, bool $withFixText = false): ScrapeResult` - `$sources` is a `Source`, a `SourceGroup` (`All`, `English`, `Spanish`, `French`, `Portuguese`, `Indonesian`, `Arabic`, `Danish`, `Norwegian`, `Swedish`), a `Collector` or an array/collection mixing them (groups are expanded, duplicates removed; large groups start many billed collector runs, so check `plan()` and set `$limit`); maps sources back to collector Actors (fewest collectors, ties go to the country collector), runs them separately and concurrently, merges and deduplicates the articles by URL; `$searchQuery` (1-100 chars) keeps only articles whose title, text or URL contain the keyword; `$startDate`/`$endDate` (`YYYY-MM-DD` or date object) bound the publication date (start not in the future, end not older than 5 years and not before start); `$limit` (0 to 10000, 0 = unlimited, above 10000 throws like the Actors' maximum, null = Actor default 100) is the maximum per collector run, not for the merged result; `$withSentiment`, `$withTags`, `$withSummary`, `$with5w1h`, `$withLanguageDetection`, `$withFixText` add optional per-article analysis to `Article::$sentiment`, `$tags`, `$summary`, `$fiveW1h`, `$detectedLanguage`, `$fixedText` (raw `?array`, null unless requested and successful)
- `Client::plan(array|Collection|Source|SourceGroup|Collector $sources): RunPlan[]` - the collector runs `scrape()` would start, no request is sent
- `Config(string $baseUrl = 'https://api.apify.com/v2', int $timeout = 900, int $requestTimeout = 90, int $maxConcurrency = 2, int $maxRetries = 3, float $retryBaseDelay = 1.0, float $retryMaxDelay = 30.0)` - retries use exponential backoff with jitter and honour `Retry-After` (seconds or HTTP date): 429, 5xx and connection failures are retried; the run-start POST only after a 429 or a failed connection, never after a 5xx or timeout (billing); `maxRetries: 0` disables retrying
- DTOs (all `final readonly`; `Article`, `ScrapeResult`, `CollectorError`, `RunPlan` implement JsonSerializable and have toArray() in the Actor's snake_case shape plus `collection` on Article, and fromArray(toArray()) restores them):
  - `ScrapeResult`: entries: Collection<int, Article>, errors: Collection<int, CollectorError>; helpers hasErrors(), isComplete()
  - `Article` (`fromArray(array, ?string $collection = null)`, collection falls back to the array's `collection` key): url: string, collection: string (collector key, e.g. `us`), title: ?string, authors: string[], datePublish: ?string, description: ?string, text: string, language: ?string, imageUrl: ?string, sourceDomain: string, type: ArticleType, error: ?string; helpers isArticle(), hasEnrichment()
  - `CollectorError`: collector: Collector, message: string
  - `RunPlan`: collector: Collector, sources: Source[]
- Enums:
  - `Source`: one case per news outlet (568), value is the Actor input key, e.g. NewYorkTimes ('new_york_times'); label(), collectors()
  - `Collector`: Es, Fr, Id, JpEn, Latam, Mx, Sea, Uk, Us, Arab, TwEn, Ng, Scandinavian, Th, KrKo, Jp, Vn, Pl, Tr, It, De, Au, Br, Ca, Ch, Gt, IdEn, IlEn, InEn, KrEn, Nl, PkEn, Py; value is the collection key (`jp-en`); actorId(), sources(), isRegional()
  - `ArticleType`: Article ('article'), Video ('video'), Audio ('audio')
- Exceptions: `InvalidInputException` (extends InvalidArgumentException; empty or non-Source sources, or an invalid option; thrown before any request), `MissingApiKeyException` (extends ApiException), `ApiException`, `RateLimitException` (retryAfter). Failing collector runs are not thrown but returned in `ScrapeResult::$errors`.

## Example
```php
use GlobalNewsScraper\Client;
use GlobalNewsScraper\Source;

$client = (new Client())->setApifyKey(getenv('APIFY_API_TOKEN'));
$result = $client->scrape([Source::NewYorkTimes, Source::BbcNews]);
$result->entries->groupBy('collection')->map->count(); // ['us' => 12, 'uk' => 9]
```
- `SourceGroup::sources(): Source[]` and `Source::language(): SourceGroup` - every source has exactly one language group
